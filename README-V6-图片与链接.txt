V6 图文链接笔记版
1. 将压缩包内的文件全部上传至 GitHub 仓库根目录，替换同名文件；保留目录结构。
2. 升级前，先在旧版首页导出三科学习数据，确认保存。
3. 进入每一道题的「我的答案笔记」，点击添加图片或添加链接。图片会压缩后保存于本机 IndexedDB，链接单独保存。
4. 首页一键备份现已包含所有图片和链接。备份文件可能较大，请保存到 iCloud Drive。
5. 不要删除主屏幕 App 或清空 Safari 网站数据。
6. 图片和链接不会自动同步到其他设备。更换设备请导出、导入 V6 完整备份。
7. 外部链接需要联网，已经保存的图片可离线查看。
8. 旧版 V5 的数据可继续读取，V5 备份不含本版本的新图片。
