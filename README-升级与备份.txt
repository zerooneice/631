2027 上体大考研抽题 · V5 稳定升级版

重要：升级前请在旧版每个科目底部点击“导出背诵进度”保存 JSON 文件，分别保存三科。
原来的学科数据仍使用 qz-2027-school / training / physiology 的本地存储键，以及 -notes、-newbank、-settings 后缀；不会在安装新版时主动清除旧数据。

更新 GitHub：
1. 解压本压缩包，上传内部全部文件到仓库 main 根目录（与 index.html 同级），替换同名文件。
2. 提交后检查 GitHub Pages / Actions 部署成功。
3. iPhone 需要联网重开 App，缓存更新可能需要第二次关闭重开才能完全生效；不要删除 App 或清除 Safari 网站数据。
4. 在首页点击“一键导出三科完整备份”，备份含所有原学习记录和新版本的抽题轮次。

功能：
- 新增模糊题库：点击「有印象·记不全」自动进入专项题库；在对应模式独立抽题。
- 生题库与模糊题库分开显示；标记为已掌握自动移出专项题库。
- 各科各筛选范围的当前抽题顺序、已抽题和剩余题数在退出/重入后保留。
- 当前筛选范围重置本轮，不影响记录和笔记。
- 首页一键导出/恢复三科 JSON。旧版每科 JSON 仍可从对应科目导入。
- 降低大面积模糊的渲染负担，简化卡片动画，并升级服务工作线程缓存。

注意：浏览器数据、桌面 App 独立数据容器、iCloud Drive 备份是不同概念；没有账号云同步。
务必在同一台 iPhone 上、同一个已安装的 App 内打开新版；如果系统把新版作为新的浏览器数据容器运行，可能需要从旧 App 导出数据再在新版导入。
